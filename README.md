# Verse Grammar

TextMate grammar for the Verse programming language developed by Epic Games.

## About Verse

Verse is a programming language designed for metaverse experiences, primarily used in Unreal Engine and Fortnite Creative.

## Features

- Syntax highlighting for `.verse` files
- Comment support (line `#` and block `<# #>`)
- Basic language constructs recognition
- Bracket matching and auto-closing

## Installation

This grammar is designed to be used with GitHub Linguist for syntax highlighting on GitHub.
